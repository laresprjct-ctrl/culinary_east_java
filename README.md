# Jatim Food Review
Aplikasi web ulasan kuliner Jawa Timur.  
Publik, mudah digunakan, dan bisa dibuka siapa saja.

## Fitur
- Tambah ulasan (nama, tempat, kota, rating, ulasan)
- Menampilkan semua ulasan
- Pencarian berdasarkan nama tempat / kota
- Data tersimpan di API publik (bukan localStorage)

## Cara Menggunakan
1. Buka halaman utama.
2. Isi form ulasan.
3. Klik “Kirim Ulasan”.
4. Semua orang bisa melihat ulasan langsung.

API: `https://jtimfood-api.onrender.com/reviews`
